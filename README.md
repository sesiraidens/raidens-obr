## Sobre

Repositorio template criado para padronizar a documentacao e estrutura de projetos da equipe RAIDENS para a OBR. Elimina a necessidade de criar estrutura do zero a cada nova edicao.

---

## Conteudo

- **templates/** - Templates padrao para README, LICENSE e .gitignore
- **docs/** - Regras da OBR, checklist de submissao, links uteis
- **examples/** - Exemplo de README preenchido e estrutura de pastas
- **scripts/** - Script para setup automatico de repositorio

---

## Como Usar

1. Clone este repositorio
2. Execute o script de setup: ash scripts/setup-repo.sh
3. Preencha os placeholders com as informacoes do seu projeto
4. Siga o checklist antes de submeter
